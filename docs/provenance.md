# Provenance

Append-only ledger of changes to this plugin.

- 2026-11-10: initial plugin. Nesting rule copied from the DeepSeek harness workspace browser (`owningParentFolder` in `@deepseek-ai/dsh-client-ui-workspace` 0.2.2, nearest strict directory ancestor, case-sensitive). Rendered as a plugin screen because `addSidebarView` is on Paseo main (commit a449271d, 2026-11-07) but absent from the 0.15.4 SDK on npm. Verified: `bun test` (2 pass), `bun run typecheck` clean, `paseo plugin install` on daemon 0.15.3 reports `running`. Requested by the repository owner.
- 2026-11-10: replaced the separate tree screen with in-place nesting of the built-in sidebar list, on the owner's request ("should integrate into the existing workspace list, not a new page"). Sidebar structure read from the Paseo 0.15.3 web UI: sections are children of one flex column, each project row has test id `sidebar-project-row-host:<serverId>:<directory>`, a folded project's `role=group` keeps one child. Verified on a throwaway daemon (0.15.3, web UI, six sample projects) in headless Chrome: order and indent applied (`acme` > `api` > `sdk`), folding `api` hides `sdk`, folding `acme` hides all four descendants, disabling the plugin clears every style, re-enabling restores them. `bun test` 2 pass, `bun run typecheck` clean. Not checked: the Electron app window, drag reordering, non-directory projects. `assets/screenshot.png` is from that sample daemon.
